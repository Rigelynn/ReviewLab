APPLICATION CONSTRUCTION · APPENDIX A1 / B1

Project reference value

qi = ∑k∈Ki ρikxik

x is the share of a component’s contribution targets supported by the application. The importance weights ρ sum to one. These values are fixed before review and hidden from agents.

Development pool: four targets per component. Independent specialist assessment is planned.
KNOWLEDGE COMPOSITION · APPENDIX A1 / B2

Project and reviewer breadth

Di = ∑k,l wikwilΔkl
Dexpertj = ∑k,l fjkfjlΔkl

w describes project content; f describes the reviewer’s publication fields. Both use the same field-distance matrix Δ. Knowledge breadth and reference value measure different aspects of a project.

GENAI REVIEW OUTPUT · APPENDIX B3

Criterion scores and direct rankings

Tji = 100 × (∑c=13 ajic − 3) / 12
Sji = 15 − ∑c=13 ajic

Each agent scores novelty, scientific value and feasibility from 1 to 5, one application at a time. The program calculates T (higher is better) and S (lower is better). A separate request asks the same agent to rank the whole pool without seeing earlier scores.

(4, 3, 5) gives T = 75 and S = 3. The three criteria assess the whole application; they are distinct from disciplinary components.

ORGANIZATIONAL OUTCOME · APPENDIX A4

Total selected value and selection loss

V(Ar) = ∑i∈Ar qi|Lm = V(A*) − V(Ar)

A* contains the m projects with the highest reference values. Compare rules using the same pool, reviewers and funding capacity. Higher selected value and lower loss indicate better selection. Reference values enter only after each rule’s priority order is fixed.

ESTIMATION BENCHMARK · APPENDIX A3

Mallows–Binomial joint estimation

Sji | pi ∼ Binomial(M, pi)|Πj | π*, θ ∼ Mallows(π*, θ)

The joint procedure fits a consensus order to the scores and separately submitted rankings. p is an estimated reverse-quality parameter: smaller means better. The fit uses no reference-value labels. For this AI pool M = 12; the distributions define the working likelihood, while the observed evaluations come from agents reading applications.

Pearce and Erosheva (2022). Joint fits use rankrate 1.2.1, matching the numerical benchmark: FV, Greedy, GreedyLocal and A*. The preview reads verified R fits for the saved evaluations; changing funding capacity recalculates portfolio outcomes. Distributional fit and score–ranking dependence will be examined in the formal study.
Interdisciplinary judgment model · planned numerical extension

Familiarity and component assessment

dijk = 1 − cos(ηj, uik)
sijk = xik + βj(1 − dijk) + σ(dijk)zijk

d measures distance from a reviewer’s knowledge to one disciplinary component. β allows familiarity-related strictness; σ controls assessment noise. The disturbance z has mean zero and variance one.

Attention and project evaluation

αijk = wike−κ(Di)dijk∑l∈Ki wile−κ(Di)dijl
yji = ∑k∈Ki αijksijk

α weights the reviewer’s attention; ρ weights the organization’s valuation. The planned simulations vary familiarity and attention to examine when each aggregation rule selects better portfolios (Appendix A2 / C2).

The completed numerical benchmark uses Binomial scores and Mallows rankings. The saved GenAI experiment obtains evaluations by reading applications. These are separate experiments; neither has yet tested the planned familiarity-dependent extension.
